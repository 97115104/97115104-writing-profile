# Austin Harshberger Writing Profile

This repository is a prompt and constraint engineering layer for AI collaborators who are asked to write, revise, or review prose in Austin Harshberger's voice. It is meant to make the writing profile strict enough to use in practice, with `writing-profile.md` as the governing source and `prompt.md` as the reusable instruction block that agents can be given at the start of a drafting or editing session. The goal is voice replication across long-form papers, blog posts, essays, and related public writing, with the local HDC paper project at `/home/x97115104/Documents/projects/oss/hdc-paper` and the published writing at `blog.97115104.com` serving as core calibration material when those sources are available. The repository should therefore be understood as an operating layer for style compliance, and not as a folder of optional examples.

The profile is intentionally treated as a constraint system and not as a loose preference sheet. An agent using this repository should read `writing-profile.md` before drafting, should obey its hard prohibitions without exception, and should use `prompt.md` to convert those prohibitions, citation habits, sentence rhythms, paragraph structures, and tonal requirements into actual behavior. The prompt is written to keep the agent inside the author's established range, namely civic, calm, evidentiary, structurally explicit, and resistant to generic AI diction. In practice, the agent should treat deviation from the profile as a failed draft condition, even when the underlying idea is useful.

The expected use is direct. Give an agent this repository, instruct it to read `writing-profile.md`, then ask it to use `prompt.md` as its operating prompt before it writes or revises any prose. When the task involves work connected to the Human Data Collective paper, the agent should compare its output against the style and argumentative structure of the HDC paper project. When the task involves essays, blog posts, or public notes, the agent should use the same profile while allowing the register to fit the target venue, with fidelity to the author's sentence rhythm, citation discipline, and measured tone remaining the controlling rule.

The important standard is that the agent should return prose that already survived the profile. A draft that contains a hard prohibition, an unsupported empirical claim, a body paragraph with no real structure, or a generic AI phrase has not finished the assignment. The agent should revise until the text is consistent with `writing-profile.md`, then return the prose with only the necessary note about missing sources, unresolved assumptions, or citation gaps.
